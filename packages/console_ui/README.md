# console_ui

The Console design system (dark-first, modeled on UniFi OS) as Flutter theme tokens and widgets. `tokens.dart` is generated from the design system's `tokens.json`. Widgets work with mouse, keyboard and a TV remote's D-pad.

Fonts: Inter and JetBrains Mono (SIL Open Font License, see `assets/fonts/OFL.txt`). The logo is for personal, non-commercial use.
